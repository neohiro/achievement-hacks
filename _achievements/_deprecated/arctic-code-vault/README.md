# 🧊 Arctic Code Vault Contributor

> **Status: `Deprecated`** — Frozen in 2023. No new accounts can earn this.

## What it was

A one-time achievement awarded to **contributors whose code was included in the 2020 GitHub Archive Program**. The program snapshotted public open source repositories on **February 2, 2020** and stored them in the **Arctic Code Vault** — a long-term archival facility in **Svalbard, Norway**, designed to last 1,000+ years.

## Visual

A blue ice cube with embedded code symbols. Frozen aesthetic. The badge is rare in the wild because it required contributing to a specific set of repositories before the snapshot date.

## Why it's deprecated

GitHub froze the achievement in 2023. The Archive Program was a one-time event; no new repositories will be added to the vault.

## What to do

Nothing. If you earned it before 2023, the badge stays on your profile forever. If you didn't, you can't.
