# 🚁 Mars 2020 Contributor

> **Status: `Deprecated`** — Frozen. No new accounts can earn this.

## What it was

Awarded to contributors whose code was part of a repository used by **NASA's Mars 2020 mission** — specifically the **Perseverance rover** and the **Ingenuity helicopter** (the first powered aircraft to fly on another planet).

The mission launched **July 30, 2020** and landed **February 18, 2021**. GitHub's Mars 2020 Achievement program was a celebration of open source software used in the mission.

## Visual

A Mars planet silhouette with the Ingenuity helicopter overlaid. Orange/red tones — the Martian aesthetic.

## Why it's deprecated

GitHub no longer issues this badge. The Mars 2020 mission has concluded, and no new repositories are being added to the achievement's qualifying list.

## What to do

Nothing. The badge remains on the profiles of those who earned it. If you didn't contribute to a qualifying NASA JPL repository before the cutoff, the path is permanently closed.
