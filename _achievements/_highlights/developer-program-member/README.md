# 🛠️ Developer Program Member

> **Status: `Unobtainable`** — requires registering as a GitHub App developer.

## What it is

Badge for members of the GitHub Developer Program — developers who build GitHub Apps or Integrations.

## Path

1. Go to https://developer.github.com/program/
2. Click "Join the Program"
3. Register
4. Badge appears automatically

## Difficulty

**Trivial** — free registration, just requires building a GitHub App.
