# 🎓 GitHub Campus Expert

> **Status: `Unobtainable`** — requires being part of a school/university and completing Campus Expert training.

## What it is

Badge for student leaders in the **GitHub Campus Program** — students who learn developer tools and run tech events at their school.

## Path

1. Be enrolled in a school/university
2. Apply to the GitHub Education program
3. Complete the Campus Expert training
4. Host or lead tech events at your school
5. Badge appears

## Difficulty

**Hard** — time investment over months. Not automatable.
