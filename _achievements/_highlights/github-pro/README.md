# 💎 GitHub Pro

> **Status: `Unobtainable`** — requires an active paid GitHub Pro subscription.

## What it is

GitHub Pro is a paid account tier. The badge appears automatically when you have an active Pro subscription.

## Path

1. Go to https://github.com/settings/billing
2. Upgrade to GitHub Pro ($4/month)
3. Badge appears automatically

## Difficulty

**Trivial** — pay $4/month.
