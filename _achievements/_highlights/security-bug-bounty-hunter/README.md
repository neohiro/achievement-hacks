# 🐛 Security Bug Bounty Hunter

> **Status: `Unobtainable`** — requires a confirmed GitHub security bug report.

## What it is

Badge awarded to researchers who **report a confirmed security vulnerability** in GitHub's own platform via the GitHub Security Bug Bounty program (run on HackerOne).

## Path

1. Find a real security bug in GitHub's own products
2. Report it via https://backerone.com/github (or https://bounty.github.com)
3. GitHub confirms and triages
4. Badge appears after resolution

## Difficulty

**Hard** — requires real vulnerability research on GitHub's platform. The payout is real money ($555–$30,000+), so the path is also a paying job.
