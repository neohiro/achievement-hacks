# 💖 Public Sponsor

> **Status: `Not yet`** — requires real $1 sponsorship via GitHub Sponsors.

## What it measures

You sponsored **at least one** open source contributor via [GitHub Sponsors](https://github.com/sponsors).

## Visual

A heart with a dollar/gift symbol. Pink/red tones. The profile animation shows a heart with a small price tag.

- Single tier, single badge.

## Tiers

| Tier | Required |
|---|---|
| Default | 1 (one-time) |

## How it works

1. Find a developer on GitHub Sponsors (e.g., https://github.com/sponsors).
2. Pick a tier (minimum $1).
3. Complete payment.
4. Badge appears.

A **one-time payment of $1** qualifies. You don't need a recurring sponsorship.

## Automated recipe

**There is no API for this.** Sponsorship requires real money and a real payment method. The "automation" is the human action of clicking "Sponsor" and entering card details.

```bash
#!/usr/bin/env bash
# earn_public_sponsor.sh — informational
echo "To earn Public Sponsor:"
echo "1. Go to https://github.com/sponsors"
echo "2. Pick any developer with a sponsorship page"
echo "3. Choose a tier (minimum \$1)"
echo "4. Complete payment"
echo "5. Done — badge appears within 24 hours"
```

## Manual recipe (the only way)

1. Open https://github.com/sponsors in a browser.
2. Search for a developer you want to support (or pick from suggested lists).
3. Choose the cheapest tier (often $1).
4. Pay.
5. Done.

**A note on ethics:** $1 sponsorships just to farm the badge are not in the spirit of open source. The honest path is to sponsor someone you actually use. Some good first targets:
- Maintainers of projects you depend on
- People who actively answer your questions in Discussions
- Friends who have GitHub Sponsors pages
